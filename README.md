# Rubika C — Personal Portfolio

A responsive personal portfolio website built with plain HTML, CSS, and JavaScript.

## Contents

- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual design
- `script.js` — mobile navigation and current year
- `assets/` — optional location for images or other assets

## Run locally

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.
3. Update any personal details or project descriptions before publishing.

## Publish to the team repository

Place this complete folder at the root of the central repository as:

`portfolio-rubika/`

Use a personal feature branch and submit a pull request to `dev`. Do not push directly to shared branches.

## Notes

The content is based on the information supplied in Rubika C's resume. No profile photo or unverified personal information has been added. The Smart Parking System is described using the provided project details. External Google Fonts are loaded when an internet connection is available; system sans-serif fallbacks are included.
